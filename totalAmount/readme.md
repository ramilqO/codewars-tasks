Наша футбольная команда завершила чемпионат.

Результаты матчей нашей команды записываются в виде набора строк. Каждый матч представлен строкой в формате "x:y", где x — счёт нашей команды, а y — счёт наших соперников.

Например: ["3:1", "2:2", "0:1", ...]

Очки начисляются за каждый матч следующим образом:

если x > y: 3 очка (победа)
если x < y: 0 очков (проигрыш)
если x = y: 1 очко (ничья)
Нам нужно написать функцию, которая принимает этот набор данных и возвращает количество очков, набранных нашей командой (x) в чемпионате по приведённым выше правилам.

Примечания:

наша команда всегда проводит 10 матчей в чемпионате
0 <= x <= 4
0 <= y <= 4
